PHASE KICKBACK

The Ancilla Turns Function Values into Phase

|−⟩ = (|0⟩ − |1⟩)/√2

Prepare the target in |−⟩. The oracle action becomes:

The target returns unchanged; the answer is encoded as relative phase on the input register.
