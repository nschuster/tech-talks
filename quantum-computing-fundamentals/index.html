START WITH THE MYTH

What quantum computing is — and is not

IT IS

  • A different model of computation
  • Built from amplitudes, phase, and measurement
  • Promising for specific problem structures

IT IS NOT

  • Every answer tried and read at once
  • A drop-in faster laptop
  • A guaranteed speedup for every task

The goal is not “more parallel guesses.” It is carefully arranged interference.

DEUTSCH–JOZSA: THE QUESTION

Is a promised function constant or balanced?

f(x)HIDDEN FUNCTION

CONSTANT

Every input returns the same bit.

0→0   1→0 or 0→1   1→1

BALANCED

Exactly half return 0; half return 1.

0→0   1→1 or 0→1   1→0

The promise matters: no other kind of function is allowed.

CLASSICAL AMBIGUITY

One answer does not reveal the class

FIRST QUERY
f(0) = 0

Could be constant-0…

STILL POSSIBLE
f(1) = 1

…or it could be balanced.

A REVERSIBLE ORACLE

Keep x; XOR the function value into y

Uf|x,y⟩ = |x, y ⊕ f(x)⟩

⊕ means XOR: flip y when f(x)=1.

|x⟩Uf|x⟩|y⟩|y⊕f(x)⟩

The box visibly spans both registers because the operation acts on both.

PHASE KICKBACK

Let the answer leave a plus or minus sign

|−⟩ = (|0⟩ − |1⟩)/√2

Prepare y in |−⟩. After the oracle, y returns unchanged.

f(x)=0 +1f(x)=1 −1
Uf|x⟩|−⟩ = (−1)f(x)|x⟩|−⟩

Plain language: the function value becomes a phase tag on x.
